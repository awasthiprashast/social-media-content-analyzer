# Changelog

## 1.0.0

- Text extraction from PDFs (layout-preserving pdf.js parsing) and images (Tesseract OCR),
  with automatic OCR fallback for scanned PDF pages.
- Explainable 0-100 engagement score across seven weighted categories, tuned per platform
  (X/Twitter, LinkedIn, Instagram, Facebook).
- Prioritised, severity-coded suggestions and a text metrics panel.
- Project hygiene: MIT license, CI workflow, editor config, dependency audit fixes.
